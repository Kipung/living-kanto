# Concurrent thought and action

A person can deliberate while their already accepted walking, work or rest continues. Background cognition has its own bounded queue and worker pool. Immediate decisions never wait for that person's thought job. Battle input and privately delivered nearby speech receive priority, with capacity reserved for urgent requests. At concurrency32: up to4 background thoughts,2 slots reserved for urgent responses, and26 ordinary requests. All channels together remain bounded by32. Concurrency below4 retains immediate scheduling without background jobs.

Background inference receives the existing private observation, current activity, and conditional concrete next-step options built at the person's actual current position. It may propose a next step or record a subjective reflection. Only a `human.deliberated` event and bounded own `cognition` history are written. It cannot move, speak, grant outcomes, change commitments, replace tasks or write canonical memories. The next immediate decision sees its earlier suggestion and must choose a currently legal action to use it. Existing task completion remains engine-grounded.

Walking progress and elapsed needs do not invalidate thoughts. New accepted choices, delivered messages, battles or changed resources supersede them. Suggestions may outlive the original location; they carry their observation boundary and never authorize execution. Current action validation remains mandatory. A thought is attempted only during a running movement/activity, no more often than30 wall seconds and300 simulated seconds per person. Both bounds apply; idle people are not polled for reflection. Battles and user trainers are excluded.

An autonomous person can answer, acknowledge or decline recorded nearby speech while moving or working/resting. Engine path steps and activity deadlines continue. Replies refer to a delivered speech ID; acceptance rechecks receipt, prior replies, current proximity and battle restrictions. Tile progress alone does not discard the reply. Forced movement and battle choices retain their existing restrictions. The scheduler does not invent a reflex, automatic reply or human action.

Pause/close cancels both channels. Already running local requests occupy their reserved slots until retirement and cannot commit into a later generation. An optional thought failure is exposed in runtime status without stopping an already accepted physical activity; required action failures retain the existing corrective retry and pause behavior. All production inference uses the configured local provider and shared audit sink. Tests use explicitly identified fixtures.

Runtime status exposes deliberating actors, accepted/stale thought counts, optional thought errors and reserved capacities. Existing person profiles show the latest thought alongside ongoing activity; full event history includes thought events. Saved patches replay without inference. No save reset or history reconstruction is required.
