# Private local inference audit

The runtime provider can capture exact fitted inference prompts and raw response text for each choice and optional text stage. Each attempt records model/protocol, actor, original observation hash, fitted-message hash, schemas, context budget, reported token usage and finish reason, stage latency and total decision latency. Raw invalid model content is retained even when the decoder rejects it. Corrective attempts are separate records. Canonical response hashes normalize JSON formatting so runtime accepted/rejected/stale/discarded/cancelled outcomes can be linked after parsing.

`LocalModelProvider.configure_trace(directory, run_id)` enables a per-run SQLite audit and shares it across inference lanes. `record_trace_outcome(observation_dict, response_string_or_choice_dict, outcome, event_id=None, reason=None, state_version=None)` records engine disposition. The sink exposes `list_records(human_id, limit, before_id)`, `get_record(trace_id)` and `status()` for the existing observer profile. This audit is never injected into a person's private observation, exported world history, or model context.

Audit files are created with owner-only permissions. Default retention is the newest 2,000 attempts within 64 MiB of serialized record payload; old audit records expire without altering canonical simulation history. SQLite uses auto-vacuum to reclaim expired records. The database's structural overhead is additional to the payload budget. Run names are hashed for filenames. Endpoint configuration and authorization headers are not logged. If model text echoes a configured endpoint or credential, that value is redacted and the record explicitly flags redaction; otherwise prompt/response text is exact. Persisted failure diagnostics use exception type names, never exception messages that may contain network or filesystem configuration.

If audit setup fails, tracing stays disabled and `audit_error` exposes the exception type; provider/controller startup and real model choices continue. Successful setup can be retried later. If audit persistence fails, `audit_error` exposes the failure type. The simulation still uses the actual returned model choice and normal validation; logging failure alone does not invent a replacement choice or pause the world. A successful write does not clear an earlier error automatically, so operators can see that the audit may have gaps. This is bounded local observability, not a replacement for canonical save/replay evidence.
