# Living Kanto interface

Served by the local FastAPI backend without a frontend build step. Create an Observer, Survival or Creative run from the top toolbar. Configure an OpenAI-compatible **local** model under Local mind connection, then Run or request one decision. Model errors are shown and pause progress.

Use Region to select any mainland inventory location. Drag and scroll to pan/zoom; select a resident from the searchable list or map, then Follow. The observer inspector shows private memories and beliefs as subjective data, alongside factual badge records. This inspector never supplies AI observations.

Survival and Creative runs create a separate persistent player. Refresh choices and select an engine legal action. Edit JSON arguments for conversation and goals. Arrow keys use offered directional walking choices. Creative changes affect the selected resident and record permanent provenance.

Factual history lists canonical committed events. Replay inspects a saved state summary without inference. Export downloads a portable save. Playback speed is a request; local inference may limit actual progress.

Presentation limitations: All 256 inventory maps have source-imported static artwork. Viridian School and Celadon roof room use source-proven zero-filled VRAM for unloaded tile704; metadata records the loader evidence. Sprites use source sheets but animation and full palette compositing remain incomplete. The battle view shows original species sprites, authoritative HP and move logs; smooth attack animation remains incomplete. Replay displays saved historical map positions and people separately from live controls.
